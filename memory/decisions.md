# 决策记录

## ADR-001
日期：2026-09-17
背景：新项目 war_shape 冷启动
备选方案：本地先搭架子再接云端 / 先接云端再搭架子
最终选择：先接云端（云端是空仓库，无冲突）
原因：空对空，先把线接通，后面推东西不打架
影响：本地主分支定为 main，对应云端

## ADR-002
日期：2026-09-17
背景：整体架构四问（载体/规模/AI/连局）
备选方案：App/大地图/全程AI/详细继承 vs 推荐方案
最终选择（用户确认）：
1. 载体=单文件网页双击即玩（零成本、离线、好分享）
2. 规模=一局一剧本，做深三国3-5个再扩
3. AI=第一版不接，写死剧本先验证玩法
4. 连局=只带一张通关卡（结局+分数+关键选择）
原因：最小成本先跑通"好不好玩"，分支可控、不引入服务器费用
影响：game.html做通用引擎，剧本按 story-xxx.js 加；通关卡为唯一跨局接口
