# 验货三步（$ARGUMENTS 可指定只验某个剧本文件，不写就全验）

1. **语法**：每个动过的 JS 跑 `node --check`。
2. **裁判**：`node check.js [文件]`。报的条数必须等于 EXPECTED，死刑清单必须为空。引擎语义变了必须同步改裁判里的模拟器。
3. **实玩**：`file://` 打不开，用 `python -m http.server <端口>` 后台起服务，浏览器走完全局，断言：走到结局、分数和选的对得上、信按时拆、控制台零报错。引擎改了要把老剧本也重走一遍，行为必须一模一样。
4. 收尾删掉 `.playwright-mcp/` 残留。

机器全绿但你没亲手玩过 = 没做完。最后一关永远是你亲手点。
